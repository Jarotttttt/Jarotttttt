### 🧠 About Me — AI Engineer & Automation Specialist

I am an **AI Engineer & Automation Specialist** with a strong passion for developing **Autonomous AI Agents**, **Multi-Agent Systems**, and **Large-Scale Web Automation**. I focus on bridging the gap between cutting-edge LLMs and real-world execution by turning manual digital workflows into autonomous, self-healing pipelines.

- 🤖 **AI & Agentic Systems**: Building intelligent multi-agent systems, autonomous task planners, LLM orchestration (Claude, Gemini, OpenAI, LangChain), and cognitive workflow tools.
- ⚡ **Web Automation & Protocol Reverse-Engineering**: Deep protocol-level automation (WhatsApp Web via `zapo-js`), undetected browser automation with Chrome DevTools Protocol (CDP), and SeleniumBase UC.
- 🛠️ **Full-Stack & Systems**: Production-ready software using Python, Node.js, TypeScript, React, Next.js, and durable SQLite/PostgreSQL databases.
- 💡 **Core Mindset**: *"If a machine can do it, a human shouldn't. Automate with precision, scale with intelligence."*
